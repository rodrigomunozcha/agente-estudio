# Etiquetas de triage

Las skills hablan de cinco roles. Esta tabla dice qué etiqueta usa este repo para cada uno.

| Rol en las skills   | Etiqueta en este repo | Significado                                   |
| ------------------- | --------------------- | --------------------------------------------- |
| `needs-triage`      | `needs-triage`        | Hay que evaluarlo                             |
| `needs-info`        | `needs-info`          | Esperando más información de quien lo pidió   |
| `ready-for-agent`   | `ready-for-agent`     | Completamente especificado, listo para un agente |
| `ready-for-human`   | `ready-for-human`     | Lo tiene que hacer una persona                |
| `wontfix`           | `wontfix`             | No se va a hacer                              |
